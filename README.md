TIDELOCK — a 5v5 plant/defuse tactical FPS set in a tidal harbour lock at dusk. The Breakers attack, the Wardens defend: plant the charge at Crane Deck or the Gatehouse and hold the site until it blows, or wipe the other side first. Bots play complete rounds — plant, detonate, round end — and the whole match runs headlessly for verification.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```
